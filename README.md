# Sistema de Contenedores en Tránsito — UNITEC U.S.A.

Gestión y tracking de contenedores de importación en tránsito.

## 🚀 Deploy en Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/TU-USUARIO/unitec-contenedores)

## 🛠️ Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Dark Mode UI

## 📦 Instalación

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000)

## 🌐 Production

```bash
npm run build
npm start
```

## 📝 Features

- ✅ Dashboard de contenedores
- ✅ 3 estados: En Tránsito, En Puerto, Llegado
- ✅ Búsqueda y filtros
- ✅ Estadísticas en tiempo real
- ✅ Dark mode elegante
- ✅ Responsive design
- ✅ Persistencia local

## 🔗 Deploy

Auto-deploy habilitado en Vercel. Cada push a `main` deploya automáticamente.
